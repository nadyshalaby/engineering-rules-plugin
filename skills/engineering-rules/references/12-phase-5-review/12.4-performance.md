# 12.4 [check] Performance

**Cost that grows with data or traffic, with the trigger condition named.**

## Method

1. For every changed path, ask what happens at ten times the data and ten times the calls.
2. Walk the domains:

| Domain | What to look for |
|---|---|
| Data access | A query inside a loop over rows; a filter that cannot use an index; a missing index on a new lookup. |
| Algorithmic | Nested iteration turning linear into quadratic; repeated work that should be hoisted out of a loop; a scan where a map would do. |
| Async | Independent awaits run one after another; a synchronous blocking call on a request path. |
| Memory | A cache with no bound and no eviction; an accumulator that only grows; a whole file buffered when it could stream. |
| Fan-out | An unbounded batch, an unbounded result set, an unbounded set of listeners. |
| Frontend | Unstable props or keys forcing re-renders; heavy work inside render; effect chains that cascade; layout thrash. |
| Payload | Serialization done more than once; a response carrying fields nobody reads; a bundle grown by a heavyweight import. |

3. **Re-judge every candidate the perf scout (9.4) staged.** Confirm it with evidence, or dismiss
   it with a reason. A staged row left unjudged is an open row.
4. Cite the catalog ID and the `file:line` in the changed code.

## Verification

1. Does every finding name the condition under which the cost bites? (yes / no)
2. Did you re-judge every staged scout row, confirming or dismissing each? (yes / no)
3. Is every finding citing a catalog ID and a `file:line`? (yes / no)
4. Did you avoid filing micro-optimizations with no measured cost? (yes / no)
5. Did you say what this check did not reach? (yes / no)

## Severity

- **Critical** — cost grows with user data or traffic on a hot path.
- **Important** — a real cost on a warm path, or an unbounded growth with a slow fuse.
- **Minor** — a constant factor on a cold path.

**Measure before optimizing, and say when you have not.** A finding with no measurement is
a candidate, and it says so.
