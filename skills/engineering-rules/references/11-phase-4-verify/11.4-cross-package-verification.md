# 11.4 [check] Cross-package verification

*Runs at verify time, on a change that spans more than one package or deployable.*

**A change that builds in one package and breaks its consumer has not been verified.**

## Method

1. **List every package the change touched**, and every package that depends on one of them.
2. **Build each dependent package**, not just the changed one. A type or signature change is
   invisible until the consumer compiles.
3. **Run each dependent package's tests**, not just the changed package's.
4. **Check the version and lockfile state.** A workspace change that needs a version bump,
   or a lockfile that did not update, breaks on a clean install and not on yours.
5. **Boot the composed system**, not the package in isolation.
6. **Exercise one real path that crosses the package boundary**, end to end.

## Verification

1. Did every dependent package build, with the output shown? (yes / no)
2. Did every dependent package's tests run, with the output shown? (yes / no)
3. Does a clean install from the lockfile still resolve? (yes / no)
4. Did the composed system boot? (yes / no)
5. Did a real cross-boundary path run end to end? (yes / no)
6. For any leg you skipped, is the skip recorded with a reason? (yes / no)
