# 4.1 [route] The routes, and how one is picked

The route table and the routing rules are inlined in `SKILL.md` under **Picking the route**
and bind from the moment the skill loads. This file carries the classification detail that
table does not have room for.

## Classifying the prompt, in order

1. **Trivial?** Check the three shapes in `SKILL.md` Definitions. A trivial ask ends after
   the answer or the one-line edit, with no ledger. If you are about to make a second edit,
   or the one line changes behaviour, it was never trivial: open the ledger now.
2. **Read-only?** Answer it. The moment an edit is decided, the ledger opens.
3. **Named a route?** The user's own words pick it. Full mode is named by phrases such as
   *"use the full workflow"*, *"do this properly"*, *"I want a work-doc"*, *"plan it first"*,
   *"full mode"*. Shaping is named by *"let's discuss"*, *"let's think"*, *"what if"*,
   *"explore the idea"*, *"what do you think"*, *"considering"*, *"thinking about"* with no
   build verb. A walkthrough by *"walk me through"*, *"trace"*, *"how does X work end to
   end"*. An audit by *"audit the codebase"*, *"audit this repo"*. Triage by a pasted batch
   of review findings or *"respond to the review"*.
4. **Otherwise quick mode.** Every substantive prompt with a build verb (`add`, `build`,
   `fix`, `change`, `refactor`, `implement`, `remove`, `rename`, `migrate`, `update`) and no
   named route is quick mode.

## What never picks a route

- The size of the diff, the number of files, or the number of packages.
- The sensitivity of the surface (auth, billing, migrations). Sensitivity raises the review
  bar inside the phases; it never changes the route.
- How long the task looks like it will take.
- Your own preference for more ceremony.

Reading a task's shape as an implied request for more ceremony is the judgment this rule
removes, because it turns a five-minute ask into a forty-minute one without anybody agreeing.
When a task looks like it will span sessions, say so in one line and offer full mode. Do not
take it.

## When two routes fit

Say so, pick one, state why in one line, and go. The tie-breakers:

- A build verb beats a discussion phrase when both are present (*"let's discuss adding X"*
  shapes; *"add X, let's discuss the details as we go"* is quick mode).
- A pasted findings batch with a request to respond is triage, even inside a running task.
- *"Walk me through this PR"* is not a walkthrough; a PR is a diff, not an entry point. It
  is a review (Phase 5 on the diff) or triage.
- A route that is not quick or full still obeys the whole always-on law.
