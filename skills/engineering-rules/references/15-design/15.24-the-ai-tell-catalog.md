# 15.24 [catalog] The AI-tell catalog

## The signatures of generated design, with stable ids

The canonical catalog of **AI tells**: the specific patterns a model produces when it tries
to "look designed", collected from production tests of generated landing pages, portfolios,
redesigns and mobile screen sets. Each carries a stable id so a finding can name the tell
instead of a feeling, a default severity, why it reads as generated, a detection hint, and
the fix direction. Read on demand by: Phase 3 for the areas the surface has, the design
scout (15.29) for the rows a grep can decide, the pre-flight (15.30), and the Phase 5
design-conformance check (12.5), which cites these ids in its findings.

**Canonical direction.** THIS file is canonical for the rows; 15.1 carries the short
always-on list, 15.22 and 15.23 carry the rules the rows enforce, and each direction profile
(15.7 to 15.18) carries its own anti-tells, which matter more than any row here because they
name that direction's lazy version.

### How to load this file

| Who | What to load |
|---|---|
| **Phase 3, building a surface** | the areas the surface has. A landing page needs Hero, Label, Punctuation, Copy, Layout, Visual, Asset; a settings screen needs State, Chrome, Visual, Type; a data view needs Layout, Type, State. |
| **The design scout (15.29)** | nothing at scan time; it cites these ids in its rows and the table below marks which rows it can decide. |
| **The pre-flight (15.30) and the conformance check (12.5)** | the whole catalog, because a page is judged once and every area applies. |
| **Anyone else** | the short list in 15.1, already in context. Come here to cite an id or read a fix. |

### Severity model

| Severity | Meaning | Examples |
|---|---|---|
| **Critical (C)** | A user cannot read, reach or use the page, or the first viewport is broken. | Unreadable button text, hero overflowing the fold, horizontal scroll on a phone, no reduced-motion path, a form below AA contrast. |
| **Important (I)** | The page reads as generated; the fix is a real change to the surface. | Every signature tell: the em-dash, the section number, the fake product UI, the beige-and-brass palette, three equal cards. |
| **Minor (M)** | A reader notices and moves on. | Title Case headers, straight quotes, a rationed middle dot used twice. |

Context moves a row one level: a Minor copy tell on a hero headline rises; an Important
layout tell inside an internal admin tool falls. The scout stages the default; the
conformance check (12.5) sets the final severity.

### ID scheme

Ids are stable slugs `tell.<area>.<slug>`, the same convention as `perf.*`, `sec.*`,
`test.*` and `style.*`. Areas: **hero · label · punct · copy · layout · visual · type ·
motion · asset · state · chrome**. Renaming an id is a breaking change to every surface that
cites it: extend, do not rename. The `Detect` column is a hint; a row marked *scout* has a
pattern in 15.29, and every other row is judged by reading.
