endpoint 1

Nearby search

GET /places/nearby?lng=&lat=&radius_m=

Finds places around a point. It is the only flow that takes a radius, and the only one that clamps it before the query runs.

MAIN src/http/nearby.ts:12–58

INPUT
  lng, lat                ── required, numbers
  radius_m                ── optional, metres

 1  IF lng OR lat is missing
      RETURN 400 "lng and lat are required"
 2  radius = CLAMP_RADIUS(radius_m)
    ── the query ──
 3  rows = APPLY_FILTERS(rows, open_now)     ── nearby passes open_now only
 4  RETURN 200 rows

CLAMP_RADIUS src/config.ts:9–14

CLAMP_RADIUS(radius_m):
  IF radius_m is absent
    RETURN           ── 1500 in the code
  RETURN clamp(radius_m, 100, 5000)
